# 🛡️ VerifyNow | Advanced Fake News Detector

**VerifyNow** is a modern web application built with Streamlit and Machine Learning (NLP) to detect and flag potentially suspicious patterns in news text and headlines.

---

# ✨ Key Features

### NLP Classification

Uses a `PassiveAggressiveClassifier` trained with `TfidfVectorizer` on the provided news dataset.

### Modern Journal UI

A custom-styled Streamlit interface with clear results and distinct indicators for authentic and suspicious text.

### Real-time Analysis

Analyzes pasted news articles, headlines, or text statements instantly.

---

# 🛠️ Tech Stack

### Frontend

Streamlit, Custom CSS

### Machine Learning

Python, Scikit-learn (`PassiveAggressiveClassifier`, `TfidfVectorizer`)

### Data Processing

Pandas, RegEx

---

# 🚀 Getting Started Locally

### Prerequisites

Make sure Python is installed on your system.

### Required Libraries

```bash
pip install streamlit pandas scikit-learn
```

---

# 💡 How to Use

# Step 1: Launch the Application

Launch the application using Streamlit.

# Step 2: Enter News Text

Paste a news article, headline, or text statement into the **Analysis Workspace**.

# Step 3: Analyze the Text

Click **ANALYZE PATTERN** to view the classification result.
